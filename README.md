# .NET Autumn Course

## Лабораторная работа №1
Роли

Спортсмен:
- Регистрация как спортсмен
- Заполнение данных о себе (ФИО, стаж, возраст, город, место тренировок, рейтинг (скорее всего будет подгружаться автоматически), разряд)
- Отслеживание статистики побед, результатов прошедших соревнований
- Отслеживание истории участия в соревнованиях
- Отслеживание в каких соревнования заявлен на данный момент
- Просмотр дальнейшего соперника по сетке в момент соревнований
- Просмотр соперников, кто заявлен на будущие соревнования
 
Тренер:
- Регистрация как тренер
- Заполнение данных о себе (ФИО, стаж, возраст, город, место тренировок, прошлые заслуги как спортсмена, если есть)
- Привязывание своих спортсменов
- Просмотр их статистики и результатов
- Заявление спортсменов на соревнования
- Отслеживание противников своего спортсмена в момент соревнований
  
Админ/Организатор соревнований:
- Регистрация как организатор
- Заполнение данных о себе необязательно
- Создание соревнований (указание места, времени, критерий)
- Обработка заявок на соревнования (принято/отказано)
- Выбор алгоритма проведения встреч (игры в группах, сетка, олимпийская сетка, круг и тд.)
  В зависимости от выбора алгоритма создаётся сетка со всеми спортсменами, которая автоматически показывает кто с кем играет в зависимости от счёта в предыдущих партиях (первая игра либо делается рандомно, либо по рейтингу)
- Ввод счёта в текущей встрече конкретных спортсменов


## Лабораторная работа №2. Code First, EF Core, PostgreSQL

**Проект:** система управления турнирами и рейтингом по настольному теннису.
Роли: спортсмен, тренер, организатор соревнований.

### Структура решения
- `TableTennis.sln`
- `src/TableTennis.Domain` — сущности и перечисления
- `src/TableTennis.Infrastructure` — DbContext и миграции
- `src/TableTennis.Web` — ASP.NET Core веб-приложение

### Сущности
| Сущность | Описание |
|---|---|
| Role | справочник ролей |
| User | пользователь (спортсмен, тренер, организатор); рекурсивная связь тренер → спортсмены |
| Competition | соревнование, создаётся организатором |
| Registration | заявка; раскрывает связь «многие ко многим» между спортсменами и соревнованиями |
